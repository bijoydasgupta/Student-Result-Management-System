HOW TO RUN
----------
Open index.html in a browser. Nothing to install.


TECHNOLOGY USED
---------------
HTML5      - the six pages and all the layout
CSS3       - one stylesheet, flexbox and grid, responsive, print style
JavaScript - all the logic, DOM updates and the data handling
localStorage - keeps the records and the login between pages


HOW THE FILES WORK TOGETHER
---------------------------
   index.html
        |  db.login(email, password)
        v
   js/data.js  <---- seedData + localStorage
        |
        |  the logged in user is saved by js/common.js
        v
   admin.html / teacher.html / student.html / parent.html
        |  db.getState(user)  ->  only the data for that role
        v
   js/admin.js, teacher.js, student.js, parent.js
        put the rows, numbers and chart bars into the HTML

Every HTML page loads the files in this order:

   css/style.css  ->  js/data.js  ->  js/common.js  ->  its own js file


WHERE THE DATA IS KEPT
----------------------
localStorage key "srms_data"  - all the records
localStorage key "srms_user"  - who is logged in right now

The first time the project is opened, the starting records inside
js/data.js are copied into localStorage. The admin dashboard has a
"Reset demo data" button to bring those starting records back.
